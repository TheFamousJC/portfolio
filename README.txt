Includes all 11 public repositories retrieved on October 26, 2026.
Each page load refreshes the public repository list from GitHub, including pagination.
If GitHub is unreachable or rate limited, the saved snapshot remains visible.
Private repositories are not included. No token is required or stored.

To host with GitHub Pages, put these files at the root of a repository and enable
Settings > Pages > Deploy from a branch. Select the branch and root folder.
Other static hosts can also serve this folder directly.

data.js contains the saved repository snapshot. github-data.json is the original
public API data. Descriptions are taken from GitHub; repositories without a
description use neutral placeholder copy. Live site links appear when GitHub's
repository homepage field is set to an HTTP or HTTPS address.
